# PIOA-M60-123BV-25

Репозиторий лабораторных работ по дисциплине «Программирование и основы алгоритмизации».

## Лабораторная работа №4

В лабораторной работе №4 расширена система управления данными,
разработанная в предыдущих лабораторных работах.

Проект реализует работу с данными о продаваемых на портале недвижимости
квартирах. Для каждой квартиры хранятся:

- идентификационный номер;
- количество комнат;
- адрес (название улицы и номер дома);
- площадь в квадратных метрах;
- стоимость квартиры в миллионах рублей.

В проекте реализованы операции:

- создание записи;
- чтение записи;
- обновление записи;
- удаление записи;
- получение всех записей;
- очистка хранилища.

Также реализована обработка ошибок ввода и проверка корректности данных и реализация СУБД в формате CSV (Доп.задача №1).
