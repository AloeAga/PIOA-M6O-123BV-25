# Лабораторная работа №4


В данной лабораторной работе №4 расширена система управления данными из предыдущих лабораторных работ. В файле `memoryLAB4.py` предоставлена in-memory база данных, содержащая информацию о продаваемых на портале недвижимости квартирах (идентификационный номер, количество комнат, адрес, содержащий название улицы и номер дома, а также площадь (кв.м) и стоимость квартиры (млн.)) с реализацией обработки ошибок ввода значений, операций создания, чтения, обновления и удаления записей.

В рамках данной лабораторной работы добавлена поддержка файловых СУБД с сохранением данных на диск. Реализованы два формата хранения: JSON (3 балла) и CSV (4 балла). Все реализации используют единый интерфейс, что позволяет легко переключаться между типами хранилищ.
